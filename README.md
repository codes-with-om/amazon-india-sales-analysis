## Project Overview
An interactive **Amazon India Sales Analysis Dashboard** built using Microsoft Power BI to analyze sales performance, profitability, order status, payment methods, fulfillment methods, and geographic performance.

The dashboard presents business data in a simple and understandable format to help management monitor performance and make data-driven decisions.

## Business Objective
The objective of this project is to transform raw Amazon India sales data into meaningful insights through interactive visualizations and key performance indicators (KPIs).

## Tools & Technologies
- **Microsoft Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Microsoft Excel** – Source dataset

## Dashboard Pages

### 1. Overall Sales & Profit Performance
- Total Sales
- Total Profit
- Total Orders
- Total Units Sold
- Average Order Value
- Profit Margin %
- Monthly Sales & Profit Trend

### 2. Category & Product Performance
- Category-wise Sales
- Category-wise Profit
- Category-wise Units Sold
- Top 10 Products by Sales

### 3. Order Status & Revenue Loss
- Order Status Distribution
- Delivered, Shipped, Returned, and Cancelled Orders
- Return Rate %
- Cancellation Rate %
- Category-wise Returns & Cancellations

### 4. Payment & Fulfillment Analysis
- Sales by Payment Method
- Profit by Payment Method
- Sales by Fulfillment Method
- Profit by Fulfillment Method

### 5. Geographic Performance
- State-wise Sales
- State-wise Profit
- State-wise Orders

## Key Features
- Interactive Year Slicer
- KPI Cards
- Category and Product Analysis
- Order Status Analysis
- Payment and Fulfillment Analysis
- State-wise Performance Analysis
